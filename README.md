# ProxySmith

Reverse proxy configuration generator for homelabbers and self-hosters.

Define your services once in a clean TOML file. Generate production-ready configs for Nginx, Caddy, or Traefik.

```
pip install proxysmith
proxysmith init
proxysmith generate --target nginx
```

---

## Install

```bash
pip install proxysmith
```

Requires Python 3.11+.

---

## Quick Start

**1. Create a config**

```bash
proxysmith init
```

Interactively generates `proxysmith.toml`. Edit it to match your services:

```toml
[global]
domain = "home.example.com"
ssl    = "auto"
email  = "admin@example.com"

[[service]]
name      = "plex"
host      = "192.168.1.50"
port      = 32400
subdomain = "plex"           # → plex.home.example.com
websocket = true

[[service]]
name       = "immich"
host       = "192.168.1.50"
port       = 2283
subdomain  = "photos"
max_upload = "10G"

[[service]]
name       = "ollama"
host       = "192.168.1.50"
port       = 11434
subdomain  = "llm"
auth       = "basic"
rate_limit = "60/min"
```

**2. Validate**

```bash
proxysmith validate
```

**3. Generate**

```bash
# Nginx (default)
proxysmith generate --target nginx --out ./output

# Caddy
proxysmith generate --target caddy --out ./output

# Traefik (produces both Docker labels and file provider YAML)
proxysmith generate --target traefik --out ./output

# All three at once
proxysmith generate --target all --out ./output
```

**4. Preview without writing files**

```bash
proxysmith generate --target nginx --dry-run
```

**5. See what changed**

```bash
proxysmith diff
```

## Commands

| Command | Description |
|---|---|
| `proxysmith init` | Scaffold a `proxysmith.toml` with examples |
| `proxysmith validate` | Lint the config, check for conflicts |
| `proxysmith generate` | Generate proxy configs |
| `proxysmith diff` | Show what would change on re-generate |
| `proxysmith doctor` | Check installed proxy tools and test generated configs |

### `generate` options

| Flag | Default | Description |
|---|---|---|
| `--target` | `nginx` | `nginx`, `caddy`, `traefik`, or `all` |
| `--out` | `./output` | Output directory |
| `--config` | `./proxysmith.toml` | Config file path |
| `--dry-run` | off | Print to stdout, don't write files |

## Service Options

```toml
[[service]]
name       = "myapp"          # required — slug identifier
host       = "192.168.1.10"   # required — upstream host
port       = 8080             # required — upstream port
subdomain  = "app"            # required — subdomain prefix

# Optional
websocket  = true             # add WebSocket upgrade headers
auth       = "basic"          # "none" | "basic" | "forward" (Authelia/Authentik)
rate_limit = "60/min"         # <number>/<s|min|hour|day>
max_upload = "100M"           # client body size limit
cors       = true             # add CORS headers
headers    = { X-Custom = "value" }  # extra proxy headers
```

---

## Global Options

```toml
[global]
domain = "home.example.com"   # required
ssl    = "auto"               # "auto" (Let's Encrypt) | "manual" | "none"
email  = "you@example.com"    # required when ssl = "auto"
```

## Generated Output

ProxySmith produces production-quality configs — not toy examples:

- **Nginx**: separate upstream blocks, full `proxy_set_header` chain, security headers, SSL hardening (TLS 1.2/1.3, HSTS, OCSP stapling), WebSocket upgrade handling, rate limiting zones
- **Caddy**: idiomatic Caddyfile syntax, per-site logging, automatic HTTPS, forward auth
- **Traefik**: Docker Compose label format + standalone file provider YAML, middleware chains, health checks

All generated files include a `# Generated by ProxySmith` header.
